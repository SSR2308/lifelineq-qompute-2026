# Measured LifelineQ results

Generated by `python scripts/summarize_results.py` from strict `load_saved` matches. This report reads actual saved counts; it does not run or modify the quantum experiments. Files from earlier source hashes or different budgets are excluded.

Computational source SHA-256: `c7339f0ce20c2bc7ca38ae24b40d9b7af9834db39edf3d4b9271b31c2c82af73`.

Tested versions: `python 3.10.11`; `qiskit 2.5.2`; `qiskit-aer 0.17.2`; `numpy 2.2.6`; `scipy 1.15.3`; `pandas 2.3.3`; `plotly 7.1.0`; `streamlit 1.65.0`; `pytest 9.1.1`.

Coverage: 90 complete fits, 630 quantum executions and 90 uniform-feasible executions. Each execution has 2,048 shots. For each of three predefined scenarios: lambda 0/1/2, p 1/2, seeds 11/22/33/44/55, two optimizer starts, at most 80 objective evaluations per start, four compiler candidates. Each fit supplies one ideal execution and six routed executions (two compiler methods × three noise levels), plus one uniform-feasible classical execution.

Every “±” below is the sample standard deviation across five fits/evaluation seeds, not a confidence interval or a pooled-shot error bar. Wilson intervals in individual JSON/CSV records describe shot uncertainty for that fixed circuit. The same evaluation seed is reused across arms of a fit; compiler effects are therefore reported as paired differences across seeds. A positive feasibility/probability delta favors searched; a negative regret delta favors searched.

## Reproduce and inspect

```bash
python -m lifelineq.experiments --preset benchmark
python -m lifelineq.experiments --preset robustness
python scripts/summarize_results.py
```

`verified_runs.csv` contains all validated execution rows; `verified_summary.csv` groups each scenario/lambda/p/method/noise cell. `verified_compiler_pairs.csv` preserves every paired difference; `verified_compiler_summary.csv` summarizes five pairs per cell. Raw JSON retains all counts, fits and compiler candidates. The source hash, scenario, configuration and dependency versions are checked before inclusion.
